# 规则分步演示与围地终局教学

用户已授权实现，沿用 B「棋谱编辑部」与现有纯前端架构。

## 范围与教学目标

- 一眼／两眼分步演示：先放入试下棋子，先检查并提掉对方无气棋块，再检查己方气。临时盘面显著标为规则演示，不写正式棋谱。
- 四课：判断空点归属；分开数活子与围住的空点；给白棋加 7.5 分并判断胜负；体验双方连续停手、标记与移除死子、确认数子。
- 新课接入章节首页；禁入点与两眼课可直接进入分步演示；生存课完成后可继续学围地，也可直接陪练。
- 与现有学习状态一致：切换页面保留进度，刷新重置；预设教学盘面不保存为正式棋谱。

## 关键约束

- 计分按本项目中国规则：移除约定死子后，活子与围住的空点都计分；白方加 7.5。被提子不另外重复加分。
- 同时接触双方的空区不属于任何一方；教学数子盘面明确双方已结束并确认活棋，不对任意中盘做领地判断。
- 终局课只使用经核验的固定死子，演示其最后一气被填后遭提走，不宣称通用自动死活判断。
- 双方连续停手才进入数子；对方继续落子会重置连续停手计数。教学完成不代表学习效果已经由用户确认。
