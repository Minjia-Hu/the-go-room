# 整盘九路讲解与独立练习

用户已授权实现，沿用 B 版界面与本地学习状态，不接外部棋力服务，不保存教学盘面为正式对局。

## 范围

- 编排一盘从空棋盘开始的完整九路示范棋谱：开局角边、观察气与提子、连接发展、留出内部空间、收完公共空点、连续停手、真实计分。逐手可回看，每手有解释；可直达下一个讲解节点，关键问题答对才能继续。
- 这是教学编排的示范局，包含明确标注的失误，不冒充高手对局或最佳下法。棋谱全部经过引擎重放，终局剩余棋块具有多个独立内部空区、没有待移除死子，比分由引擎计算。
- 六道独立练习：不同棋形的接出、提子解围、连接各两题。初始不显示目标、气或候选答案；先找危险棋块，再试下、检查后果并解释原因。
- 接受所有经规则验证、满足本题目标的落点。失败时解释当前变化，若能直接提走目标则允许查看实际白棋回应。提示由用户主动请求，区分本次未用提示、重试后完成与借助提示完成。
- 首页及策略课末尾进入整盘讲解；整盘讲解进入独立练习；练习完成可以去陪练。切页保留，刷新重置，与现有课程一致。
