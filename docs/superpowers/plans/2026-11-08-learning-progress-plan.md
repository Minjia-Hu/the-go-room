# 学习进度保存

用户已确认先完成学习进度保存，再准备开源。本轮不改变仓库可见性、不部署、不增加课程或电脑棋力。

## 记录范围

- 以稳定的章节与内容 ID 记录 29 个单元：5 关规则、2 个规则慢镜头、8 个生存场景、4 课终局、3 课策略、1 盘讲解、6 道独立练习。
- 只持久化版本号、各单元的最好完成方式和最近访问单元。存储键为 `the-go-room.learning.v1`，与棋谱、陪练偏好隔离。不保存棋盘、试下、答案、题内步骤或随机状态。
- 完成依据使用现有课程状态：规则步骤全部结束、慢镜头原因答对、生存练习完成、终局和策略课完成、整盘走到结尾且关键问题全答对、独立练习完成找棋、试下确认和原因回答。打开、浏览或跳过不算完成。
- 规则、慢镜头、策略、整盘及有引导的课程标为“跟着引导完成”，不冒充独立掌握。可请求提示的练习按现有状态区分提示与演示；独立练习另区分无提示重试后完成。
- 同一题重做保留最好结果：演示 → 提示 → 无额外帮助完成；独立练习在无提示时，未出错完成优于重试后完成。引导课仍只记引导完成。这里的“独立”是一次尝试的完成方式，不代表从未见过题目或已掌握棋力。

## 恢复与界面

- 刷新后，教学页定位到待继续单元。最近单元未完成就回到该题起点；已经完成则从后面的单元开始寻找未完成项，必要时回到目录前面。全部完成后允许回看最近一课。
- 同一页面会话中切换导航仍保留题内状态；刷新只恢复位置。整盘示范作为一个单元，未完成时从开头重看。
- 首页增加学习手记、完成总数、继续学习、各题完成方式。生存场景可分别进入引导与检验题；慢镜头、独立练习提供展开目录。
- 已有记录与本次练习状态分开展示；六道独立练习和两个慢镜头的章节衔接使用跨刷新的完成记录。
- 清除必须二次确认。清除学习记录和内存中的课程状态，不影响已保存棋谱、当前正式对局或陪练设置。
- 读到未知课程 ID 时忽略旧条目；损坏或不兼容版本给出提示，不在初次读取时覆盖原始数据。有新的学习动作或明确清除后才尝试保存。写入失败时保留本次内存操作并说明刷新可能恢复旧记录。
