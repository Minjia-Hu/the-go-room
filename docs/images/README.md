# README 展示图片

这些图片用于项目介绍；历史验收截图仍在 `docs/qa/` 中保留。

- `home.png`：2026-11-14 从本地运行页面截取，新浏览器会话下的首页初始状态，1280 × 720，应用内容对应 `000357a`。
- `practice-demo.gif`：2026-11-16 基于 `113bb58` 重新录制。通过本地开发服务器，在 Chromium 中真实操作“救棋，不一定是往外伸”，直接捕获无损 PNG 画面后转换为 1080 × 810、约 40 秒的循环 GIF，保留鼠标移动和点击提示。

录制顺序：原图 → 选择 A，向上延伸 → 确认后观察黑棋被提 → 选择 B，提子救棋 → 确认后阅读白棋回应与原因 → 选择正确原因。鼠标在按钮与棋盘变化之间连续移动，结果和解释处保留阅读停顿。

浏览器录制不包含系统鼠标，因此只在录制会话里添加跟随真实鼠标事件的指针与点击光圈；该覆盖层不进入应用代码。棋盘、落子、提子和反馈文字均来自实际页面，没有改写。从进入题目后开始捕获，再缩放和压缩画面；不是把旧截图补成鼠标动画。

导出时使用统一调色板、最高 15 帧／秒的鼠标动作采样，并合并相同画面的停留时间。避免先转成有损视频再编码 GIF，减少静止区域的压缩噪点和重复数据。当前文件为 628,452 字节（约 628 KB），169 帧、39.67 秒；相比上一版的 6,093,364 字节减少约 90%，阅读停顿仍然保留。

录制时确认两种选择的结果、正确原因与完成状态，无意外滚动或页面脚本错误。检查转换后的首帧、鼠标移动、点击反馈、提子结果、原因选择与末帧；中英文 README 共用同一文件，同时保留静态截图链接，方便逐字阅读。
