- `practice-demo.gif`：2026-11-15 基于 `aca6b16` 重新录制，替换原先的六张关键状态截图合成版。通过本地开发服务器，在 Chromium 中真实操作“救棋，不一定是往外伸”，录制连续视频后转换为 1080 × 810、15 帧／秒、约 40 秒的循环 GIF。

录制顺序：原图 → 选择 A，向上延伸 → 确认后观察黑棋被提 → 选择 B，提子救棋 → 确认后阅读白棋回应与原因 → 选择正确原因。鼠标在按钮与棋盘变化之间连续移动，结果和解释处保留阅读停顿。

浏览器录制不包含系统鼠标，因此只在录制会话里添加跟随真实鼠标事件的指针与点击光圈；该覆盖层不进入应用代码。棋盘、落子、提子和反馈文字均来自实际页面，没有改写。仅裁去进入题目前的导航过程，再缩放和压缩画面；不是把旧截图补成鼠标动画。

录制时确认两种选择的结果、正确原因与完成状态，无意外滚动或页面脚本错误。检查转换后的首帧、鼠标移动、点击反馈、提子结果、原因选择与末帧；中英文 README 共用同一文件，同时保留静态截图链接，方便逐字阅读。
