## 发布设置

只公开清理后的独立仓库，原归档继续私有。`main` 要求通过 PR 合并，必须通过 GitHub Actions 的 `check` 检查且分支与主分支同步；管理员也受约束，禁止强推和删除。单人维护不要求另一位审批人；合并前必须解决讨论，并保持线性历史。

已启用 Dependabot 漏洞提醒和自动安全更新 PR、密钥扫描与推送保护。验收时开放的 Dependabot 告警和密钥告警均为 0；这是当时扫描结果，不代表永远没有漏洞。仓库已添加围棋、学习及技术栈 topics，主页链接指向实际在线站点。

Pages 使用手动触发的 GitHub Actions 工作流。后续推送不会自动更新线上网页；需在 `main` 合并后再次运行部署工作流。

## 匿名浏览器检查

使用没有登录信息的新 Chromium 浏览器会话，实际访问 HTTPS 线上地址；不是本地开发服务器。桌面视口为 1280 × 900，手机模拟视口为 375 × 667。

- 首页与静态资源正常加载，无横向溢出；Logo 可以返回首页。
- 完成第一课落子后进入第二课，刷新恢复第二课，完成记录保留。
- 练习中确认错误延伸，看到实际提子反馈；重选提子救棋并解释原因，刷新后保留“重试后完成”。课程续读位置不被练习改动。
- 陪练试下、确认、电脑应手和退回一回合正常；再次落子后约定结束、确认数子，保存并进入复盘。
- 复盘可以跳到开头并逐手回看；刷新后已完成棋谱仍在。
- `LICENSE.txt`、`THIRD_PARTY_NOTICES.md`、`third-party-licenses.md` 均返回 HTTP 200，内容包含相应许可说明。
- 手机模拟下首页、练习列表与做题页无横向溢出，试下后整张棋盘和确认按钮同时在视口内；完成并刷新后，独立完成记录保留。
