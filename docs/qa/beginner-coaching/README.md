## 试用任务

运行 `npm run dev`，打开终端显示的地址。从教学页“保住自己的棋”进入。以下由项目负责人体验后填写，不以工程测试替代。

- [ ] 在第二个认险局面中指出哪块棋有危险、最后一口气在哪里，说明白棋怎样提。
- [ ] 比较伸出与提子解围；说出气如何变化，知道暂时解围不代表以后不会被吃。
- [ ] 连接两块棋，解释斜着靠近为什么不算相连，以及哪些气现在共用。
- [ ] 在两眼图中说出白棋进入一处时为何下不了；不要只背“两眼活棋”。
- [ ] 在陪练中根据试下提示改变一次选择，看懂一次提子，再退回最近一回合试另一种选择。
- [ ] 空盘或没有紧急危险时，主动请求提示，找到一个可尝试的方向，并用自己的话说出为什么试这个点。

若仍只能随便点、只认按钮而无法指出棋块/空点，记录卡住的场景与那句不明白的提示，优先改讲解。获胜或过关次数不是唯一标准。
