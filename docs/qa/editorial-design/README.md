# B「棋谱编辑部」正式版验收 · 2026-11-07

项目负责人在三案对比后选定 B，本次将该方向整合至正式 React 应用。

## 整合内容

- 首页采用纸色、墨色、宋体、扉页引言、棋盘图注和「壹／贰／叁」目录。
- 正式目录完整展开五关规则教学、四课生存练习及陪练入口；首页可直接开始第一课或体验生存练习。
- 练习、陪练、数子与复盘共用棋书式版面。操作按钮采用无衬线字体，主要确认动作使用墨色实底；正文与标题使用系统宋体。
- 真实棋盘采用浅木色与纸页边框。红色目标圈、空心气标记、试下虚线、字母与死子标记保留；复盘蓝色归属底纹与现有文案保持一致。
- 桌面棋盘与讲解并排；手机改为上下布局。未引入外部图片、字体服务或依赖。
- 复用正式规则引擎、AI 和课程流程；未将 demo 的两个固定落点逻辑带入应用。原始三个 demo 保留供回看。
