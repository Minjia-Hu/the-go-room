# 界面美化验收 · 2026-11-07

## 范围

- 统一纸色、墨绿、宋体标题及按钮、导航、面板样式。
- 首页新增静态棋盘插画、第一课入口和陪练入口区；插画不接受落子，不作为教学题。
- 棋盘采用柔和木色渐变，棋子增加光照和阴影。字母标记绘制在选中圆点上方，避免选中后遮住文案引用的 A / B。
- 桌面棋盘与讲解并排，滚动时保留棋盘；手机上下排列并收起装饰插画。尊重减少动态效果的系统偏好。
- 未引入新依赖、网络图片或字体请求。

## 验证

`npm test`（186 个）、`npm run build`、`npm run lint` 均通过。

使用 `npm run dev -- --host 127.0.0.1` 启动，并用本机 Chromium 实际操作：

- 首页第一课入口可用，键盘 Enter 可以落子。
- 原五关与四课八个生存场景走通；完成认险后，字母 A 仍清晰可见。
- 陪练试下、确认、页面切换取消预览、退回重试均正常。
- 320、390、768、1024 像素宽度的首页和对局页无横向溢出。
- 手机触屏试下、确认；关闭陪练并刷新后仍保留设置；禁用 localStorage 时仍可操作。
- 真实对局完成 101 手、4 次提子对照，标记与取消死子、确认数子、刷新读取棋谱均正常；实际查看终局区域与复盘面板。
- 上述检查未出现浏览器运行错误或控制台警告。
