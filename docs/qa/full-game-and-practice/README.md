# 整盘九路讲解与独立练习验收

日期：2026-11-08。沿用 B「棋谱编辑部」，纯前端、本地运行。

## 内容核验

- 示范局从空 9 路棋盘开始，67 次合法落子与两次停手，共 69 手。每手有解释，按开局、危险、中盘、安定、收尾、终局六段组织。
- 第 17 手后左上白棋恰好只剩一气；第 18 手白棋忽视危险；第 19 手黑棋实际提掉这一颗白子。全盘只发生这一次提子，各中间盘面均无零气棋块。
- 最终双方各为一大块，均具有多个分离的内部空区，无待移除死子，无公共空点。黑 34 活子 + 7 空点 = 41；白 32 活子 + 8 空点 = 40，加 7.5 后白胜 6.5。
- 逐手与讲解点导航得到同一棋谱；跳转不能绕过六处未回答的关键问题。回看保留已答记录，重新学习重置当前课程。
- 六道练习均不预先标目标、气或候选答案，各恰有一块仅一气的黑棋，且存在经引擎验证的合法解法。覆盖 L 形多子接出、提子解围、两块棋连接及旋转、干扰棋变式。
- 解法按目标棋块的气、实际提子和连接结果接受；另有测试证明同一题可接受不同正确落点，不依赖预设答案坐标。
- 错误接出仍只剩一气时不算成功；可观察白棋真实提子的回应，回原图再试。确认与原因回答都有门槛。
- 提示需主动请求，第一层只给思路，第二层才标棋块；记录本次提示与需要重试的判断，区分辅助完成和本次未用提示完成。

## 请项目负责人试用

1. 首页“从看懂到自己下”中打开“一盘九路，从头到尾”。可先用讲解点模式，再逐手回看不理解的部分。
2. 到终局时尝试自己解释：黑棋吃过白棋，为什么最后还是白棋赢？什么时候该处理危险，什么时候检查边界和公共空点？
3. 进入六道独立练习，先不点提示，自己找一气棋块、选点、看后果并解释原因。留意哪些题需要重试，哪些题需要标出棋块才能理解。
4. 去陪练试一盘，记录课程里会做、实战里却看不出的具体局面。

示范局是教学编排，包含标注的失误，不作为最佳手或高手棋谱。练习只核验当前任务与局部后果；暂时多了气不等于永久安全，完成题目也不等于已验证实际棋力。
