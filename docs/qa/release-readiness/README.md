# 发布前修复验收 · 2026-11-14

本轮只处理本机路径、当前发布记录、生存练习完成等级；课程卷目布局保持原样。没有重写 Git 历史、修改仓库可见性或部署网站。

## 行为

- 生存题答错棋块、气、眼或原因，非法落点，以及确认未达到任务目标的走法，计入本次重试。
- 合法试下、比较不同落点不算错误；两眼题按要求试白棋禁入点也不算错误。
- 四道无引导生存题与六道独立练习一致：有错误时记“重试后完成”，使用提示或演示时优先记对应辅助方式。
- 重新开始清零本次错误次数；后来独立完成可升级最好记录，后续较差尝试不降级。引导课仍按引导完成记录。
- 旧存储只保存完成等级，没有错误次数，无法追溯更正；保留旧记录，不改存储版本、不批量降级。
- 练习不改变课程页面或最近学习位置；重试完成的题仍保留推荐资格。

## 浏览器实际操作

通过 `npm run dev` 打开真实浏览器，操作“练”页的“换到边上，自己找一找”：

1. 先点错误位置，再正确选棋块与最后一口气，显示“重试后完成”。
2. 返回列表并刷新，仍显示重试记录，独立完成数仍为 0，推荐按钮仍进入该题。
3. 重新独立完成，记录升级为“独立完成”，独立完成数变为 1。
4. 本次操作未观察到浏览器控制台错误。
