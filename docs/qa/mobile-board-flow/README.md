## 其他验证

- 390 × 844、320 × 667、667 × 375、1440 × 1000：对局无水平溢出，桌面仍为左右布局。
- 根字号增加到 24 px 后无水平溢出，允许竖向滚动，仍可确认落子。
- 数子输入在 375 × 350 缩小视口中可填写并提交；这只是可滚动性验证，不等同真实系统键盘测试。
- 浏览器回归通过原五关、八个生存场景、陪练预览、键盘操作、确定性重试；13 个原课程完成记录正常写入。
- 学习记录回归通过刷新恢复、完成方式、清除隔离、存储失败、手机触摸与 320–1440 宽度检查。
- 本轮自动测试 257 个通过；构建、lint 和 diff 空白检查通过。浏览器无页面错误。

## 尚需真机试用

没有用实体手机测试。请在手机 Safari 中下几回合，重点试四角和边线、先试下再确认、提子后重试，以及终局课数字输入。浏览器工具栏、底部手势区、系统键盘与手指准确度不能由以上模拟验证。大字号、更矮可视区域和较长课程说明允许滚动；不以缩小棋盘或隐藏关键解释换取首屏容纳。
