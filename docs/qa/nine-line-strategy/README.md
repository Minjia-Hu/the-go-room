## 请项目负责人试用

从首页“九路策略入门”开始。每课先选你直觉上想下的一手，再慢慢点白棋回应与黑棋后续，最后看另一种走法。

完成后试着回答：

1. 为什么这道题要先救棋？接出一次是否代表永远安全？
2. 为什么角上的示意图更省子？围成一圈是否就能保证得到这些分？
3. 什么时候可以先不追白棋？本例两条路线分别保住或丢掉了什么？

然后到陪练中尝试每手先检查危险。流程和棋形已验证，能否迁移到陌生局面需要初学者实际试用；目前没有棋力评级或通用策略分析。
