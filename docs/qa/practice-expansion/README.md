# 练习内容扩充验收

日期：2026-11-14。分支：`codex/expand-practice-library`。

## 范围与内容

「练」由 10 题扩为 22 题、六组能力。原 10 道课程配套题的位置、课程顺序、稳定 ID 和共用完成记录不变；课程主线仍有 29 个单元。新增题仅在「练」中出现。

| 能力 | 新题 |
| --- | --- |
| 认危险 | 边上三颗棋，共用几口气；弯着连接，也算同一块 |
| 找出路 | 角上的三颗棋；弯形黑块，出口在哪里 |
| 提子 | 被夹住的黑棋；边线上的紧急救援 |
| 连接 | 两块棋之间的缺口；角旁的三颗棋 |
| 先后判断 | 能吃一颗，要先吃吗；白棋能追，自己能等吗；救棋，不一定是往外伸；先去角上，还是补上缺口 |

八道专项局面复用现有认险与独立练习流程。先后判断新增“选下法 → 试下 → 确认 → 白棋回应 → 解释原因”流程，支持原图、黑棋落子后、白棋回应后三种对照。试下比较不计错，确认错误选择或答错原因才计重试；主动提示记辅助完成。这里只比较给定局部变化，不声称最佳手或已经做活。

## 数据与课程隔离

- 新题使用 `practice/` 稳定 ID，沿用本地记录格式和最好成绩规则，旧记录可读取。
- 新题完成不改变 `session.page`、`lastVisited`、课程 29 个单元的计数或“续读”位置。
- 练习推荐覆盖全部 22 题，跳过独立完成题。旧 10 题全部完成后仍会推荐新题。
- 主动打开相关讲解才切回课程。提子救棋关联“给自己的棋找出路”；追子判断关联“什么时候先不追了？”。
- 清除学习记录同时清除课程与专项完成记录，提示文案明确范围。
