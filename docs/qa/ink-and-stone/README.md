# 「墨与印」正式版验收 · 2026-11-13

项目负责人从三套新样稿中选定 A「墨与印」，Logo 选定「一子一气」，本次整合至正式 React 应用。

## 整合内容

- **配色与字体**：宣纸底、墨色文字，朱砂只用于目标、气、当前课程等需要注意的地方；标题、正文和按钮使用系统楷体，英文名与数字用 Georgia。没有引入外部字体或图片。
- **Logo 与导航**：「一子一气」标识（一颗墨子落在棋盘一角，正下方的朱砂点是它最后的一口气），替换原来的四方块和 favicon；favicon 在深色标签栏改用白子。导航为单字「学 · 弈 · 复」，无障碍名称仍是「教学 / 对局 / 复盘」。
- **首页**：竖排题目「一子一气」，墨圈里的棋盘可以直接下。点 A 或 B 的结果、提示和后续按钮就地显示在旁边，不跳页。落子、数气、白棋提子都由规则引擎判定（`heroRunner.ts`），不是写死的结果。
- **卷目**：六章做成竖排书脊，同一时间展开一卷，展开后是完整课程目录；已读为实心墨点，下一课标朱砂圈和「续读」。默认展开下一课所在的卷。手机上改为竖向手风琴。
- **学习记录**：保留原有统计、继续学习与清除记录，新增 29 段墨条进度。
- **课程、陪练、复盘**：沿用原有版面，换成纸面棋盘、墨色棋子和朱砂标记。

## 已完成的检查

- `npm test`：40 个测试文件、273 个测试通过。新增首页练习的引擎测试，以及首页下棋、卷目展开、续读标记的界面测试。原有测试因为课程链接收进卷轴，改为先点开对应章节再点课程。
- `npm run build`、`npm run lint` 通过。
- 用 Playwright 驱动 Chromium 实际点击并截图：首页初始、下 A、下 B 后看白棋提子；规则课程、生存练习、终局课程、对局页、复盘页。
- 1440、1000、390 像素宽度的首页，以及 390 像素的课程页和对局页，均无横向溢出，页面没有运行错误。
- 没有在实体手机上验证。
