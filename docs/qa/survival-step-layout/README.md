# 生存课分步布局验收

日期为 2026-11-21，在 `survival-step-layout` 分支本地验收。[V2EX 帖子的 1 楼和 5 楼](https://www.v2ex.com/t/1257558) 提到课程操作顺序、下一课入口和信息密度的问题。

## 本轮变化

- 「保住自己的棋」的通用页面在标题下显示当前步骤和一句任务。找出路的引导题还会显示已比较的种数，确认一种走法后回到选点步骤。
- 棋盘旁集中显示引言或反馈，以及当前操作。试下后最多一个实心确认按钮，两眼题回答原因时显示两个次要选项。
- 「讲解与图例」和「看看对照」默认收起。完成后显示和学习记录一致的完成方式，主按钮标明下一题、下一课或终局的去向。「练」继续使用自己的按钮文案。
- 只有生存课底部的回看和跳题链接改成灰色小字。第一题仍使用独立的引导页面。

## 浏览器走查

使用 Playwright 操作本地 Chrome。每个视口都从「学」的卷目进入，依次完成八个场景，再通过末题主按钮进入「围地与终局」。第一题按原有「找棋／找气」引导验收。其余七题核对步骤编号、任务、主按钮数量和去向，以及「讲解与图例」的默认收起状态。展开认危险与两眼的对照并切换盘面，确认找出路引导题显示「已比较 1 / 2 种」，且已确认过的试下点不会再次出现确认按钮。

| 视口 | 结果 |
| --- | --- |
| 1440 × 900 | 八个场景和下一课入口走通。末题的主按钮通往终局，旁边的「开始我的陪练」为次要按钮。 |
| 375 × 667 | 同一路径走通，无横向溢出，步骤标签不低于 12 px。两眼题的选项在棋盘下方，可向下滚动选择。 |

两个视口都使用新的学习记录，从「练」直接完成四道生存检验题和两道认危险专项题。完成方式写入各自的记录，返回列表和刷新后可见「独立完成」，最近学习位置保持原值。完成按钮使用「下一道练习」。本次走查未触发全题独立完成后的「返回练习列表」状态。浏览器未报告页面错误。

实体手机 Safari 和其他浏览器未做验收。规则、终局、策略、整盘讲解与独立练习沿用原布局，本次仅验证从最后一道生存题进入终局的入口。
