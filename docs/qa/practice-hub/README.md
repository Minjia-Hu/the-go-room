## 相对计划的调整

1. 按负责人最新要求从 `main` 开分支，而非计划中的旧基点名称。
2. 两道提子独立题指向「给自己的棋找出路」：题目要求通过提子救黑棋，该讲解实际比较延伸与提子两种救法，比单独介绍提子规则更贴切。其余映射按题目内容核对后保留。
3. 给 `recordLearningProgress` 增加可选 `visit` 控制。只保持 `session.page` 不变还不够：刷新恢复可能已选中下一课，但 `lastVisited` 仍指向此前完成的一课。练习保存必须明确保留原值；课程入口默认行为不变。
4. 两个做题组件增加可选 `nextLabel`，使练习入口显示「下一道练习／返回练习列表」，课程入口仍用原文案和流程。
5. 四项导航需要更多宽度，因此只追加窄屏品牌字号、Logo 与导航间距样式，保留导航 44px 点按区域。样式仍采用 `practice-` 前缀，没有修改原样式规则。
6. 提交按三个可检查的整体组织：目录与进度隔离；页面、路由、样式与交互测试；文档与截图。
